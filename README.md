# Social Network: публикации, исходники изображений и личные сообщения

Социальная сеть, в которой к посту можно прикрепить готовые изображения и отдельные исходники. Пользователи публикуют записи, ставят лайки, комментируют, подписываются друг на друга и общаются в личных сообщениях.

## Что сделано

- Регистрация и вход с JWT, редактирование профиля и аватара.
- Лента, посты с несколькими изображениями и скачивание исходников.
- Лайки, комментарии, подписки и настройки приватности.
- Диалоги и уведомления через Socket.IO.
- Переключение темы и звуковые уведомления.

## Как устроен проект

Клиент написан на Next.js 14, React и TypeScript. Состояние хранится в Redux Toolkit, запросы идут через Axios. Стили собраны в SCSS Modules.

Express обрабатывает REST-запросы, Sequelize работает с MySQL. Socket.IO передаёт события сообщений и уведомлений. Пароли хешируются через bcryptjs, JWT проверяется в middleware. Загруженные изображения хранятся в `server/static`.

| Папка | Что смотреть |
| --- | --- |
| `client/src/pages` | Страницы Next.js Pages Router |
| `client/src/features` | Redux-срезы и запросы |
| `client/src/components` | Лента, посты, диалоги и модальные окна |
| `server/controllers` | Логика API |
| `server/models` | Модели и связи MySQL |
| `server/socket.js` | События Socket.IO |

## Запуск

Нужны Node.js 24, npm и Docker с Compose.

```bash
git clone https://github.com/kvantoniY/Social-Network.git
cd Social-Network
cp server/.env.example server/.env
docker compose up -d --wait
npm ci --prefix server
npm ci --prefix client
npm start --prefix server
```

Во втором терминале из корня проекта:

```bash
npm run dev --prefix client
```

Сайт: http://localhost:3000. API: http://localhost:3001. MySQL: локальный порт 53307. Таблицы создаются при старте сервера.

В Windows PowerShell используйте `Copy-Item` вместо `cp`. Если PowerShell блокирует `npm.ps1`, запускайте `npm.cmd` вместо `npm`.

## Что проверить

1. Создайте аккаунт на `/auth` и войдите.
2. Опубликуйте запись с изображением и исходником. Проверьте ленту и скачивание.
3. В отдельном браузере создайте второго пользователя. Подпишитесь на первого, поставьте лайк и оставьте комментарий.
4. Отправьте личное сообщение и проверьте его получение во втором браузере.

Сборка: `npm run build --prefix client`. Результаты проверки: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Ограничения

Это учебная версия. Таблицы создаются через `sequelize.sync()`, отдельной истории миграций нет. Клиент рассчитан на API по адресу `localhost:3001`. Перед внешним развёртыванием нужны проверка прав во всех операциях, настройка адресов и обновление зависимостей.
